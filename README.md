# Сайт Жанар Сулейменовой · «Переход»

Статичный сайт для GitHub Pages: HTML, CSS и немного JavaScript, без сборки. Любую правку можно сделать прямо в браузере на GitHub (кнопка с карандашом) — через минуту она появится на сайте.

## Страницы

| Файл | Что это | Задача в запуске |
| --- | --- | --- |
| `index.html` | Главная: кто Жанар, «Узнаёшь себя?», история, метод «5 этапов», три формата, лестница продуктов, отзывы, Telegram, вопросы | Прогрев: куда ведём из шапки профилей и роликов |
| `razpakovka.html` | Лендинг «Осенняя распаковка личности»: 15 мест по 35 000 ₸ до 8 ноября, запись в WhatsApp | Запуск 1, 26 октября – 8 ноября |
| `kod-2027.html` | Бесплатный мини-расчёт по дате рождения и «Код 2027» | Часть для бота: ведёт в Telegram-бот с меткой `site_calc_N` |
| `intensiv.html` | Анонс бесплатного интенсива «Переход в 2027», 8–10 декабря | Длинный запуск; регистрация откроется 23 ноября |

`assets/style.css` — все стили, `assets/app.js` — ссылки, калькулятор и мелкая логика, `assets/favicon.svg` — значок вкладки.

## Что заменить перед запуском

1. **Фото.** Положить в `assets/` файлы со съёмки 22 октября (JPG, вертикальные 4:5, до 400 КБ каждый):
   - `photo-hero.jpg` — портрет для главной;
   - `photo-story.jpg` — Жанар в жизни, с семьёй или в горах;
   - `photo-razpakovka.jpg` — Жанар за работой с клиентом;
   - `photo-intensiv.jpg` — Жанар у ноутбука, вечерний свет.
   Пока файла нет, на его месте аккуратная заглушка с подписью.
2. **Бот.** Ссылка `https://t.me/perehod_zhanar_bot` — заглушка. Заменить в одном месте: `assets/app.js`, объект `LINKS.bot`, и в двух прямых ссылках (`kod-2027.html`, кнопка `#r-bot`). Метки старта: `site_main`, `site_calc`, `site_calc_1…9`, `kod2027`, `intensiv`.
3. **Тексты чисел 1–9** в мини-расчёте — черновик. Жанар утверждает их в `assets/app.js`, объект `NUMBERS`.
4. **Цены и даты** указаны в HTML-страницах текстом. Поиск по файлам: `35 000`, `45 000`, `129 000`, `8 ноября`, `8–10 декабря`.
5. **Отзывы.** Блок на главной ждёт реальных отзывов после первых распаковок (со 2 ноября) — только с письменного разрешения клиентов.
6. **Интенсив.** С 23 ноября заменить кнопку канала на регистрацию в боте (подсказка в комментарии в `intensiv.html`).
7. **Картинка для превью ссылок.** После съёмки добавить `assets/og.jpg` (1200×630) и строку `<meta property="og:image" content="https://ДОМЕН/assets/og.jpg">` в `<head>` каждой страницы.

## Публикация на GitHub Pages

Settings → Pages → Build and deployment → Source: **Deploy from a branch** → Branch: **main**, папка **/ (root)** → Save. Через 1–3 минуты сайт откроется по адресу `https://shumniyvlad-cell.github.io/zhanar-perehod/`.

## Свой домен с Рег.ру

1. Купить домен в аккаунте Жанар на Рег.ру.
2. В Рег.ру: Домены → домен → DNS-серверы и управление зоной → добавить записи:
   - `A` для `@` → `185.199.108.153`
   - `A` для `@` → `185.199.109.153`
   - `A` для `@` → `185.199.110.153`
   - `A` для `@` → `185.199.111.153`
   - `CNAME` для `www` → `shumniyvlad-cell.github.io.`
   Старые A-записи для `@` (парковка Рег.ру) удалить.
3. В GitHub: Settings → Pages → Custom domain → вписать домен (например, `zhanar-perehod.kz`) → Save. GitHub сам создаст файл `CNAME` в репозитории.
4. Через 15 минут – 24 часа, когда DNS обновится, включить **Enforce HTTPS** на той же странице.
